# StudyFlow — AI Student Planner SaaS

A responsive student planner web application built with HTML, CSS, and vanilla JavaScript.

## Features
- Dashboard with task statistics and progress bars
- Create study tasks with subject, due date, priority, and duration
- Mark tasks complete, filter tasks, and delete tasks
- Study schedule and upcoming deadlines views
- Local study-plan helper with focus sessions and breaks
- Adjustable daily study goal
- Light/dark theme toggle
- Responsive desktop and mobile layout
- Saves tasks and goals in browser localStorage

## Run locally
Extract the ZIP and open `index.html` in a modern browser. No build tools are required.

## Deploy on GitHub Pages
1. Create a repository named `ai-student-planner-saas`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch**, choose `main` and `/(root)`, then save.
5. Once deployed, the URL format will be `https://YOUR-GITHUB-USERNAME.github.io/ai-student-planner-saas/`.

## Project note
This is a front-end educational demo. The study-plan helper uses local JavaScript rules; it is not connected to a real AI model or backend. A production SaaS would need authentication, a database, and a secure AI API integration.
